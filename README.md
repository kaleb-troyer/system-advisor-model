This project was created to perform techno-economic analyses on a large scale 3rd generation concetrating solar power plant with particles as the thermal carrier. If you need to make use of this code for your own research, the best option is to follow the installation guide for SSC as provided on NREL's official github repository to set up dependencies. Then, clone this repository, create a build directory, and within the build directory run `cmake ..` and `make`.

This project was created to perform techno-economic analyses on a large scale 3rd generation concetrating solar power plant with particles as the thermal carrier. The code provided here is not currently in a state for compiling or distribution. If you need to make use of this code for your own research, the best option is to follow the installation guide for SSC as provided on NREL's official github repository. Then, it will be necessary to replace the contents of the relevant files with those from this project. Otherwise, let this repository serve as a convenient means of viewing the models deployed and their interactions. 

In the future, I intend to make this repository fully distrubutable.
